# WickedWhims - The most (in)famous Sims 4 Mod

WickedWhims is a mod for The Sims 4 that expands the game's relationship, attraction, and adult gameplay systems. It adds advanced customization options, animations, autonomy features, and additional gameplay mechanics while integrating directly with The Sims 4.

## Features

- **Standalone Mod**: Install the mod directly into your The Sims 4 Mods folder — no additional applications or dependencies required.
- **Advanced Attraction System**: Adds a customizable attraction system that affects how Sims perceive and interact with one another.
- **Relationship & Romance Features**: Expands romantic interactions and relationship gameplay beyond the game's default systems.
- **Adult Gameplay**: Adds mature gameplay systems and interactions intended for adult players.
- **Animation Support**: Supports custom animations created specifically for WickedWhims.
- **Autonomy Options**: Provides extensive controls for autonomous behaviors and interactions.
- **Customization**: Configure gameplay systems, notifications, autonomy, and other features through the in-game WickedWhims settings.
- **Mod-Friendly**: Designed to work alongside other compatible The Sims 4 mods and custom content.
- **Lightweight**: Runs directly within The Sims 4 with no separate launcher or external program required.

## Installation

### Windows

1. Download the latest WickedWhims release.
2. Extract the downloaded `.zip` file.
3. Locate your The Sims 4 Mods folder:
   `Documents\Electronic Arts\The Sims 4\Mods`
4. Copy the WickedWhims files into the Mods folder.
5. Start The Sims 4.
6. Open **Game Options > Other**.
7. Enable:
   - **Enable Custom Content and Mods**
   - **Script Mods Allowed**
8. Apply the changes and restart The Sims 4.

> **Important:** Do not place the mod too deeply inside multiple subfolders, as The Sims 4 has restrictions on how far it can detect script mods.

## Usage

1. Launch The Sims 4.
2. Load a household or start a new game.
3. WickedWhims will automatically initialize when the game loads.
4. Use the WickedWhims interactions and settings available through your Sims and the in-game menus.
5. Customize attraction, autonomy, relationship, and other gameplay settings to your preference.

---

## Updating

1. Download the newest version of WickedWhims.
2. Completely remove the previous WickedWhims files from your Mods folder.
3. Extract the new version into your Mods folder.
4. Start The Sims 4.
5. Verify that **Script Mods Allowed** remains enabled.

> **Tip:** Avoid installing multiple versions of WickedWhims at the same time, as this can cause conflicts or unexpected behavior.

---

## Disabling / Removing

To temporarily disable WickedWhims:

- Remove the WickedWhims files from your Mods folder.
- Start The Sims 4 normally.

To reinstall the mod later, simply place the current WickedWhims files back into the Mods folder.
